**Purpose**
This is a USB HID joystick that accepts MIDI commands to control SimpleFOC-driven motors (USB Composite Device).

**Aircraft Control Profiles** (Implemented)
Three pre-configured MIDI CC mappings for different aircraft types:

- **Airbus A320**
    - Throttle (CC#7: 0-180°)
    - Flaps (CC#11: 0-180°)
    - Trim (CC#64: endless rotation, -100 to +100%)
    - Spoilers (CC#2: 0-180°)
    - Landing Gear (CC#32: 0-180°)

- **Cessna 172**
    - Throttle (CC#7: 0-180°)
    - Flaps (CC#5: 0-180°)
    - Trim (CC#64: endless rotation, -100 to +100%)
    - Landing Gear (CC#35: 0-180°)

- **Glider**
    - Spoilers/Airbrakes (CC#2: 0-180°)
    - Trim (CC#64: endless rotation, -100 to +100%)

**Profile Selection**
Profiles can be selected **without recompiling**:
- **Serial**: Commands `A0` (A320), `A1` (Cessna), `A2` (Glider)
- **MIDI**: CC#121 with value 0 (A320), 1 (Cessna), or 2 (Glider)

See [AIRCRAFT_PROFILES.md](AIRCRAFT_PROFILES.md) for detailed configuration.

**Hardware & Limitations**
The firmware controls a single motor at a time. With single-motor hardware, one axis is active per profile (typically trim or throttle). Multiple motors can be configured at build time.

Buildable configurations:
- **pico_1motor_endless** — Single endless motor (current hardware, trim-like)
- **pico_1motor_limited** — Single 0-180° motor (throttle/flaps-like)

Build with: `platformio run -e pico_1motor_endless`
